# Vel v0.3.3 Release Draft

## GitHub release title

**Vel v0.3.3 — Application Foundations and ABI Readiness**

## Release notes

Vel v0.3.3 is a foundations and correctness release for native application-core development. It aligns the active compiler, installer, roadmap, changelog, and desktop sample metadata on version `0.3.3`, adds a release-readiness matrix, and improves host-shim validation behavior.

### Highlights

- Standardized active version metadata on `0.3.3` across the compiler, Windows installer, README badge, roadmap, changelog, and desktop sample manifest.
- Added `docs/V0.3.3_READINESS.md`, which distinguishes implemented capabilities from unfinished release work and defines a defensible v0.3.3 release boundary.
- Preserved v0.3.2 design and readiness documents as historical records rather than rewriting past release documentation.
- Corrected oversized file-write validation in the host runtime shim so inputs larger than the 64 MiB limit consistently return `VEL_STD_IO_ERROR`, including when the data pointer is null.
- Updated the public runtime-header comment to clearly identify the provisional shell-backed process API in v0.3.3.

### Validation

- The project configured and built successfully with CMake and GNU C++ using `VEL_VERSION=0.3.3`.
- The complete local CTest suite passed: **8/8 tests passed**.
- `vel version` reports `Vel 0.3.3` with Linux x86-64, macOS x86-64, and Windows x86-64 native backend declarations.
- `git diff --check` completed without whitespace errors.

### Current platform boundary

Vel v0.3.3 remains suitable for native console programs and application-core projects. It is not yet a complete GUI framework. Stable windowing, event handling, graphics, resource bundling, module imports, multi-file compilation, a versioned recursive aggregate ABI, structured diagnostics, and a safe argument-vector process API remain future work or release gates.

The provisional process function delegates commands to the host shell and must only be used with trusted, developer-controlled input.

### Upgrade and compatibility notes

This release does not introduce a stable public versioned aggregate ABI or a Vel-level standard-library import system. Projects relying on those capabilities should continue to treat the relevant runtime and host-shim interfaces as provisional. Cross-platform CI validation on Linux, macOS, and Windows x86-64 should pass before publishing the `v0.3.3` tag.
